# Local HTTP captures

Captured by `scripts/s11_ui_seed.py` from the real FastAPI application and disposable Mongo database.
TARIC data comes from the official EU consultation; each response preserves `source_url`, date, fetched time and conditions. `manifest.json` records the local HTTP request and capture SHA256. Earlier captures retain their original source timestamps in the JSON and the seed request log in UI evidence.

Business records are explicitly labelled local test inputs, created through authenticated HTTP APIs. The suspended licence `UI-TEST-NOT-VALID` is not issued by an authority and cannot authorise filing. Transit/ENS sandbox specimens come from `backend/tests/fixtures/ncts_ics2/samples.py`; export uses `backend/tests/fixtures/tulli/export-declaration.json`. Responses and MRNs are generated by the actual backend sandbox, never browser mocks. They are not Tulli/EU production acceptance evidence.

No credentials or session tokens are captured. Regenerate using the commands in `notes/s11/ui.md`.
